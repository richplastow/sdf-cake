Rendering cake with signed distance functions

- repository: <https://github.com/richplastow/sdf-cake>
- homepage: <https://richplastow.com/sdf-cake/>

## Usage

To run `index.html` locally, you'll need to use a web server:

```bash
open http://localhost:2222
npx serve docs -p 2222
```

Use `ctrl+c` to stop the server.
